安全

安全，是默认设置。

Lumen 把云端操作当作文件操作来对待：先确认范围，再执行；信息不完整时，宁可停下来。

01

密钥进钥匙串

AccessKey Secret 与 STS Token 只保存在 macOS 钥匙串；权限默认跟随 Bucket，不擅自改写对象 ACL。

02

覆盖必先确认

复制、移动、重命名和撤销都会检查目标对象；只有开启版本控制并取得精确版本时才允许覆盖。

03

传完核对一遍

上传与下载都核对 OSS 返回的 CRC64 校验值，对得上才算完成。

04

更新先验签

软件内更新经 Ed25519 验证安装包后再安装，安装完成自动退出并重新打开。

常见问题

你可能会问。

Lumen 是什么？

Lumen 是一款原生 macOS 阿里云 OSS 客户端，用来在 Mac 上浏览、整理、上传和下载对象。它是独立开源项目，不是阿里云官方产品。

支持哪些 Mac？

Lumen 1.0.3 支持 Apple Silicon Mac，需要 macOS 15 或更高版本。

账号凭证保存在哪里？

AccessKey Secret 和 STS Token 保存到 macOS 钥匙串。账号名称、地域等非敏感设置保存在本机偏好设置中。

软件会自动更新吗？

会。在「Lumen → 检查更新…」中可以立即检查；发现新版本后，点击安装即可完成签名验证、替换并自动重新打开。

删除后可以撤销吗？

Bucket 开启版本控制时，刚删除的项目可以立即按 Command–Z 撤销。未开启则删除是永久的。

Lumen 是开源软件吗？

是。Lumen 采用 MIT License 开源，可以自由使用、修改和分发；使用时需保留版权与许可证声明。

它会管理 Bucket 或控制台资源吗？

不会。Lumen 专注对象浏览、整理、上传、下载与分享，不创建 Bucket，也不管理未完成分片等控制台资源。

可以让 AI 直接操作我的 OSS 吗？

可以。内置 MCP 服务器 lumen-mcp，一条命令注册到 Codex、Claude、Cursor 等客户端后，AI 就能用自然语言浏览 Bucket、上传下载文件、生成临时下载链接。凭证保存在 macOS 钥匙串，与 App 账号相互独立。查看 AI · MCP 接入指南。
