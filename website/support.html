支持

连接阿里云 OSS、传输文件和恢复对象时，可以先看这里。应用里也有一份可离线打开的帮助。

无法连接账号

  1. 确认使用 RAM 子用户，而不是主账号 AccessKey；从仅允许访问所需 Bucket 的最小权限开始。
  2. 检查 AccessKey ID、Secret、可选 STS Token 与地域是否匹配。临时 Token 过期后需要重新填写。
  3. 使用自定义 Endpoint 时填写完整主机名；私有网络地址只有在当前 Mac 能访问对应网络时才可用。
  4. 如错误包含权限拒绝，请在阿里云控制台核对列举、读取、上传、删除或复制操作所需的 RAM 权限。

上传或下载失败

短暂断网、限流和 OSS 服务端故障会自动重试。大文件上传与下载会保存检查点；在传输中心暂停后，可从已经完成的分片或字节范围继续。

下载不会覆盖本地同名文件。若继续或重试不可用，请查看任务说明；常见情况是原文件已移动、云端对象已变化，或 macOS 不再允许访问之前选择的目录。

删除后能否恢复

Bucket 开启版本控制时，刚删除的项目可以立即按 Command–Z 撤销。未开启版本控制时，删除是永久的。

跨 Bucket 操作为什么会经过这台 Mac

同一账号、同一地域的 Bucket 使用 OSS 云端复制。跨地域或跨账号时，Lumen 会在确认页明确显示“通过这台 Mac 中转”，先下载到受控临时目录并校验，再上传到目标。移动仅在全部目标复制完成后删除来源。

账号列表异常

Lumen 会保留上一份可读取的账号配置。主配置损坏时会尝试自动恢复并保留损坏文件；如果备份也不可读，请先不要覆盖本地应用数据，然后复制诊断信息并提交 Issue。

更新没有出现

在菜单栏选择“Lumen → 检查更新…”。自动检查可在“设置 → 通用”中开启。网络代理或无法访问 GitHub Releases 时，更新检查会失败，可从发布页手动下载最新版本。

提交可复现的问题

在 Lumen 中选择“帮助 → 复制诊断信息”，然后创建结构化 Issue。附上最小复现步骤、实际结果与期望结果。

截图和录屏请使用虚拟数据，或遮盖账号、Bucket、对象名、路径与 URL。不要提交 AccessKey、Secret、Token 或签名 URL。安全漏洞应使用私密报告。
