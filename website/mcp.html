lumen / ai / mcp

让 AI 直接操作
你的 OSS

lumen-mcp 是 Lumen 内置的 MCP（Model Context Protocol）服务器。注册到 Codex、Claude Desktop、Claude Code、Cursor、Trae 等 AI 客户端后，一句话就能浏览 Bucket、上传下载文件、生成临时下载链接。

三步接入

1

准备 Node

需要 macOS 与 Node ≥ 18。终端里 node -v 检查；没有的话用 Homebrew 一行装好。

$ node -v
# 没有输出 v18+ 就执行：
$ brew install node
2

配置凭证

npx 按需下载 lumen-mcp（内置 macOS 双架构二进制，无需编译）。填入 RAM 子账号 AccessKey，凭证只保存在 macOS 钥匙串。

$ npx lumen-mcp auth
# 支持多账号：--list / --use / --remove / --test
3

一键注册

自动检测本机已安装的 AI 客户端并写入 npx -y lumen-mcp，重启客户端即可使用。

$ npx lumen-mcp install
# 或指定客户端：install --client codex
然后直接对话：「列出我的 OSS Bucket」、「把桌面的 hero.png 上传到 lumen-assets 的 assets/2026/ 目录，再给我一个 24 小时有效的链接」。

没有 Node？也可以从源码构建（克隆仓库后 swift build -c release，用二进制绝对路径运行）。

提供的能力

工具说明
list_buckets列出账号下所有 Bucket（名称、地域、创建时间）
list_objects按文件夹层级浏览对象；delimiter 传空字符串可递归列举
upload_file上传本机文件到 OSS，返回对象 URL；Content-Type 按扩展名推断
download_file下载对象到本机；本地已有同名文件时不覆盖，报错提示换路径
presign_url为私有 Bucket 的对象生成带签名的临时下载链接（默认 1 小时）

除工具外，服务器还内置 2 个提示词，可在客户端的 Prompts 面板一键使用：

提示词说明
lumen-oss-expert把 Agent 定位为 OSS 操作专家：先浏览再操作、删除前确认、私有桶自动给临时链接
oss-batch-upload批量上传工作流：确认目录 → 展示清单 → 逐个上传保留目录结构 → 汇总报告

握手时服务器还会下发 Agent 使用说明（instructions），支持客户端会直接展示并用于约束 AI 行为。

支持的客户端

以下客户端可由 lumen-mcp install 自动检测并注册：

  • Codex
  • Claude Desktop
  • Claude Code
  • Cursor
  • Trae
  • Windsurf

其他支持 stdio 传输的客户端（VS Code Copilot、Cline、Qoder 等）可手动配置：

{
  "mcpServers": {
    "lumen": {
      "command": "npx",
      "args": ["-y", "lumen-mcp"],
      "env": { "LUMEN_MCP_DEFAULT_BUCKET": "my-bucket" }
    }
  }
}

env 里的 LUMEN_MCP_DEFAULT_BUCKET（可选）设置默认 Bucket：设置后 bucket 参数对 AI 变为可选，桶名会直接出现在工具描述中，任何 AI 客户端都能看到；AI 仍可显式指定其他 Bucket。

各客户端的配置文件位置与差异见 GitHub 上的完整 MCP 文档。JSON 配置合并写入并保留 .bak 备份，不影响其他 MCP 服务器。

安全边界

凭证隔离AccessKey Secret 与 STS Token 只存 macOS 钥匙串，AI 客户端接触不到凭证本身，与 Lumen App 账号相互独立
最小权限建议使用只授予目标 Bucket 必要动作的 RAM 子账号
操作范围AI 只能执行浏览、上传、下载和签名链接；删除、覆盖、批量操作前会先向用户复述范围并确认
不覆盖下载遇到本地同名文件会报错而不是覆盖，与 App 的安全边界一致

常见问题

连接失败检查客户端配置里的二进制路径是否为绝对路径、文件是否有执行权限
弹钥匙串授权窗重新编译后二进制签名变化所致，属正常现象，点一次「始终允许」即可
上传报签名错误运行 lumen-mcp auth --test 验证凭证与地域是否匹配
想换账号lumen-mcp auth --use <名称> 切换活动档案后重启 AI 客户端
移除注册lumen-mcp uninstall，或加 --client 指定客户端

更多细节与故障排查见 docs/mcp.md；问题反馈请到 GitHub Issues。
