# Lumen 0.0.5 Release Checklist

Release target: `0.0.5` (`CFBundleVersion` 5), Apple Silicon, macOS 15+.

## Source and behavior

- [ ] Full automated test suite passes with no failures.
- [ ] Release build analysis passes with no warnings or errors.
- [ ] Finder-style selection, inline rename, Return, Esc, `⌘↓`, double-click, search filtering, and failure recovery are verified.
- [ ] App icon source files, canvas sizes, and subject footprint are unchanged from 0.0.4.
- [ ] README and release notes describe 0.0.5 accurately.

## Artifact and update feed

- [ ] `dist/Lumen-0.0.5.dmg` exists and passes `hdiutil verify`.
- [ ] Mounted app reports version 0.0.5, build 5.
- [ ] App and embedded Sparkle framework pass strict code-signature validation.
- [ ] Public build is non-sandboxed, ad-hoc signed, and does not enable hardened runtime.
- [ ] Appcast retains 0.0.4 and lists 0.0.5/build 5 first.
- [ ] Appcast enclosure length equals the DMG byte length.
- [ ] Sparkle Ed25519 signature verifies with the configured release key.
- [ ] Packaged app launches successfully from the mounted DMG.

## GitHub publication

- [ ] Release evidence and SHA-256 are committed on `main`.
- [ ] Tag `v0.0.5` points to the verified release commit.
- [ ] `main`, tag, DMG, and appcast are pushed to GitHub.
- [ ] GitHub Release `v0.0.5` is public and marked latest.
- [ ] Public DMG and appcast hashes match the local release artifacts.
- [ ] Latest appcast publishes build 5 before build 4.
- [ ] The 0.0.5 package is accepted by the Sparkle signature verifier, proving the 0.0.4 → 0.0.5 update path.

## Known distribution constraint

The public build remains ad-hoc signed and unnotarized because no Apple Developer ID identity is installed. Gatekeeper rejection on a clean first download is therefore expected and must be documented; Sparkle update authenticity is independently enforced with Ed25519.
