# Lumen 0.0.3 Release Checklist

## Finder-style interaction

- [x] Grid single-click selects and visibly highlights the item.
- [x] Grid double-click selects first, then opens a folder.
- [x] Clicking blank grid space clears selection.
- [x] Command and Shift selection behavior is covered by model tests.
- [x] List view uses native macOS `Table` selection and columns.
- [x] Escape, arrows, Shift-arrows, Return, Space, and Delete are wired to the focused browser.
