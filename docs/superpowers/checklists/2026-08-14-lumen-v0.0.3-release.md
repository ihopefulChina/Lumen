# Lumen 0.0.3 Release Checklist

## Finder-style interaction

- [x] Grid single-click selects and visibly highlights the item.
- [x] Grid double-click selects first, then opens a folder.
- [x] Clicking blank grid space clears selection.
- [x] Command and Shift selection behavior is covered by model tests.
- [x] List view uses native macOS `Table` selection and columns.
- [x] Escape, arrows, Shift-arrows, Return, Space, and Delete are wired to the focused browser.
- [x] Selection state and activation hints are exposed to VoiceOver.
- [x] Reduced-motion alternatives are used for workspace transitions.
- [x] Dark appearance was visually checked with a real OSS listing.
- [ ] Recheck light appearance and increased contrast after the Mac is unlocked.

## Safety and correctness

- [x] Object names and local download paths reject traversal.
- [x] Downloads and renames never silently overwrite an existing item.
- [x] Stale account, Bucket, listing, and inspector responses cannot overwrite current state.
- [x] Multipart failures abort exactly once; owned temporary files clean up exactly once.
- [x] Failed uploads and downloads retain exact retry destinations.
- [x] Public ACL choices show a persistent warning.
- [x] Updater accepts only the exact versioned DMG from the Lumen GitHub release path.

## Release gates

- [x] Full Debug test suite passes after Finder and updater changes.
- [x] Debug clean test passes; the real OSS test is skipped without its explicit compilation flag.
- [x] Release clean build and analyze pass without code warnings.
- [x] Real OSS smoke passes only under `lumen-v003-smoke/` and leaves it empty (xcresult: 1 passed, 0 failed, 0 skipped).
- [x] `Lumen-0.0.3.dmg` passes version 0.0.3 (3), code-signing, read-only mount, expected non-notarized Gatekeeper rejection, and launch checks.
- [ ] Public GitHub release is non-draft, non-prerelease, and its downloaded SHA-256 matches.
