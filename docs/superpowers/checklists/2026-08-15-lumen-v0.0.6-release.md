# Lumen 0.0.6 Release Checklist

Release target: `0.0.6` (`CFBundleVersion` 6), Apple Silicon, macOS 15+.

## Source and behavior

- [ ] Full automated test suite passes with no failures; only the credential-gated real OSS smoke test skips.
- [ ] Release build analysis passes with no warnings or errors.
- [ ] Object rename, folder rename, same-Bucket move, successful undo, conflict refusal, retry retention, scope gating, selection restoration, and favorite restoration are verified.
- [ ] Text-editing Undo, the Edit-menu `⌘Z` command, actionable banner timing, and separate action/dismiss targets are verified.
- [ ] Copy, upload, folder creation, and delete remain explicitly non-undoable.
- [ ] README and release notes describe 0.0.6 accurately.

## Artifact and update feed

- [ ] `dist/Lumen-0.0.6.dmg` exists and passes `hdiutil verify`.
- [ ] Mounted app reports version 0.0.6, build 6, and arm64 architecture.
- [ ] App and embedded Sparkle framework pass strict code-signature validation.
- [ ] Public build is non-sandboxed, ad-hoc signed, and does not enable hardened runtime.
- [ ] App icon source hashes, canvas dimensions, and non-transparent subject bounds match v0.0.5.
- [ ] Appcast lists build 6 first and retains builds 5 and 4.
- [ ] Appcast enclosure length equals the DMG byte length.
- [ ] Sparkle Ed25519 signature verifies with the configured release key.
- [ ] Packaged app launches successfully from the mounted DMG.

## GitHub publication

- [ ] Release evidence and SHA-256 are committed on `main`.
- [ ] Tag `v0.0.6` points to the verified release commit.
- [ ] `main`, tag, DMG, and appcast are pushed to GitHub.
- [ ] GitHub Release `v0.0.6` is public and marked Latest.
- [ ] Public DMG and appcast hashes match the local release artifacts.
- [ ] Latest appcast publishes build 6 before builds 5 and 4.
- [ ] The public 0.0.6 package is accepted by Sparkle's signature verifier.

## Known distribution constraint

The public build remains ad-hoc signed and unnotarized because no Apple Developer ID identity is installed. Gatekeeper rejection on a clean first download is therefore expected and documented; Sparkle update authenticity is independently enforced with Ed25519.
