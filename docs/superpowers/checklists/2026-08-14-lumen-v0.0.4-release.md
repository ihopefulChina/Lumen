# Lumen 0.0.4 Release Checklist

## Finder-style organization

- [x] Folders remain before files and can be sorted by name, date, size, or kind.
- [x] Sort field and direction survive relaunch.
- [x] Favorite account, Bucket, and prefix locations survive relaunch and open from the sidebar.
- [x] Internal drag and drop moves objects into folders without overwriting a destination.
- [x] Context-menu copy and paste duplicates objects without overwriting a destination.
- [x] Folder rename preserves relative descendants and rejects a destination inside itself.
- [x] Incomplete listings block prefix copy, move, rename, download, and deletion.

## Credentials and transfer integrity

- [x] New AccessKey Secret and STS Token values are stored in the macOS Keychain.
- [x] Legacy plaintext values remain until Keychain write and read-back both succeed.
- [x] Legacy plaintext storage is removed after a complete migration.
- [x] CRC64/XZ matches the published `123456789` check vector.
- [x] Upload, multipart completion, download, and preview compare the OSS CRC64 header when present.
- [x] A failed download checksum never replaces the final local file.
- [x] Verified transfer jobs surface an “已校验” state.

## Signed software updates

- [x] Sparkle is pinned to version 2.9.2 in `Package.resolved`.
- [x] The app feed URL is fixed to the Lumen GitHub Release `appcast.xml` asset.
- [x] The Ed25519 public key is embedded; its private counterpart remains in the login Keychain.
- [x] The public build preserves the 0.0.3 data location and uses Sparkle's supported non-sandboxed installer path.
- [x] Update archives are required to pass signature verification before extraction.
- [x] Automatic-check preference and manual-check actions are forwarded to Sparkle.
- [x] The generated appcast signature and enclosure length match the final DMG.

## Release gates

- [x] Full Debug clean test passes with only the explicitly gated real OSS test skipped.
- [x] Release clean build and static analysis pass without code warnings.
- [ ] Real OSS smoke passes under `lumen-v004-smoke/` and leaves the prefix empty.
- [x] Mounted DMG reports version 0.0.4 (4) and passes deep code-signature verification.
- [x] The installed app launches and its signed Sparkle updater starts without configuration errors.
- [ ] Local and public DMG SHA-256 values match.
- [ ] Public GitHub Release is non-draft, non-prerelease, and marked Latest.
