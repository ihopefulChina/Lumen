# Lumen 官网设计规范

日期：2026-08-15  
目标地址：`https://ihopefulchina.github.io/Lumen/`

## 目标

为 Lumen 建立一个可信、克制、可长期维护的中文官网。页面要在十秒内说明：Lumen 是一款原生 macOS 阿里云 OSS 客户端，它用接近访达的交互浏览和整理对象；访客可以立即下载当前版本，也能清楚看到系统要求、安全边界和项目状态。

官网不得使用虚构评价、虚构用户数量、夸大式性能数据、生成式插画或与产品无关的渐变装饰。所有能力表述必须能够在当前版本和 README 中得到验证。

## 参考与取舍

- Things：保留单一产品主张、真实产品图和短章节叙事；不使用 Lumen 尚不具备的奖项与媒体背书。
- CleanShot X：保留清晰的功能分段和 Mac 原生定位；不复制密集功能墙和销售话术。
- Raycast：保留首屏直接下载和键盘效率表达；不采用大型互动装置、玻璃视觉或未经验证的可靠性数字。

## 视觉方向

### 色彩

- `Lumen Blue #087CFA`：唯一主强调色，来自应用图标与 macOS 选中态。
- `Canvas #F4F6F9`：页面冷灰背景。
- `Paper #FFFFFF`：产品窗口、信息面和按钮反相区域。
- `Ink #11141A`：标题与正文主色。
- `Slate #616874`：次要说明文字。
- `Hairline #DCE1E8`：边界与分隔线。
- `Night #111722`：安全章节的深色底。

禁止紫色霓虹、多彩光斑、暖米色模板背景和大面积径向渐变。蓝色只用于交互、路径和少量结构提示。

### 字体

- 标题、正文、按钮：`-apple-system, BlinkMacSystemFont, "SF Pro Display", "PingFang SC", sans-serif`。
- 路径、快捷键和版本标签：`ui-monospace, "SFMono-Regular", Menlo, monospace`。

不加载外部字体，避免额外网络依赖，并保持真正的 macOS 字感。

### 布局

- 最大内容宽度 1180px；文本行长控制在约 42–68 个中文字符。
- 桌面首屏为左文案、右图标；其下是真实应用窗口的大幅展示。
- 功能章节采用交替的文字与真实截图/轻量界面片段，不使用同尺寸卡片矩阵填满整页。
- 移动端保持单列、44px 以上点击区域和无横向滚动。

### 标志性元素

页面使用“路径栏”作为章节导航语言：`OSS / Bucket / 素材 / 2026`。蓝色选中带和细路径线从真实 Lumen 界面抽取，用于连接核心章节。这是结构线索，不是背景装饰；滚动和动画均可关闭。

## 页面结构

1. 顶部栏：图标、Lumen、功能/安全/开始使用/GitHub、下载按钮。
2. 首屏：标题“把 OSS 放回熟悉的窗口里。”，一句事实描述，下载 0.0.6 与查看源码；明确 Apple Silicon、macOS 15+。
3. 真实产品展示：`docs/browser.png`，配路径栏和“原生 macOS / Finder 式操作 / 阿里云 OSS”短标签。
4. 三个功能章节：
   - 浏览：账号、Bucket、网格/列表、搜索、快速查看、收藏。
   - 整理：拖放、重命名、同 Bucket 移动、冲突保护、`⌘Z` 单级安全撤销。
   - 传输与分享：文件夹结构、大文件分片、CRC64、链接格式与临时签名 URL。
5. 安全章节：钥匙串、CRC64、Ed25519 更新、不会静默覆盖；使用深色底形成一次明确节奏变化。
6. 开始使用：下载、拖入“应用程序”、添加账号；展示真实账号设置截图。
7. FAQ：免费与许可现状、系统要求、首次打开、凭证存储、自动更新、支持范围。
8. 末尾下载与页脚：当前版本、Release、Issue、GitHub。

## 文案原则

- 用短句描述实际动作，不写“重新定义”“革命性”“极致”等空泛词。
- 不声称 Lumen 是官方阿里云产品；明确它是独立项目。
- 下载链接固定到 `releases/latest/download/Lumen-0.0.6.dmg`，版本升级时由发布流程同步更新。

## 交互与无障碍

- 锚点滚动使用 CSS，并尊重 `prefers-reduced-motion`。
- 导航在窄屏改为可换行的精简布局，不引入汉堡菜单脚本。
- 所有图片包含准确替代文本和固有尺寸，非首屏图片延迟加载。
- 焦点态清晰；按钮和链接可用键盘访问；颜色对比满足 WCAG AA。
- FAQ 使用原生 `details/summary`，无 JavaScript 依赖。

## 技术与发布

- 纯静态 HTML/CSS，不引入框架、外部字体、第三方分析或 Cookie。
- 网站源码位于 `website/`，资源使用相对路径，兼容 GitHub Pages 项目子路径 `/Lumen/`。
- GitHub Actions 仅上传 `website/` 目录为 Pages artifact；不把项目文档和构建产物暴露为站点文件。
- 页面包含 canonical、Open Graph、favicon、manifest、robots 与基础结构化数据。
- 发布后校验 HTTPS、状态码、静态资源、下载链接、移动端布局和 Pages 工作流。

## 自我审视

最容易落入模板感的风险是“大标题 + 截图 + 三张圆角卡片”。本方案通过真实路径栏、非对称章节、单次深色安全区和真实设置界面建立产品自己的节奏。视觉仍保持克制：路径元素若不能帮助理解，就不出现；动画若不能表达层级，就不添加。
