# Lumen 1.0.2

这是一个小修复版本，重点让「传输完成时显示通知」真的生效。

## 修复

- 设置里「全部完成时显示通知」的开关现在会和系统通知权限保持一致。
  - 之前如果用户拒绝过系统的通知授权，开关仍可能显示「开」，但通知其实发不出来。
  - 启动时会自动对齐状态；如果系统权限被拒，开关会自动回到「关」。
  - 每次在设置里重新打开开关都会再尝试请求一次授权。
- 前台运行时完成传输，通知横幅会正常弹出并可以带声音（之前会被折叠到通知中心）。
- 通知投递失败会写入 `NSLog`，方便后续诊断。

## 系统要求

- macOS 15 或更高版本
- Apple Silicon Mac

> 目前安装包使用 ad-hoc 签名（暂未配置开发者证书）。首次打开如果被 macOS 拦下，在访达中右键 Lumen 选择「打开」即可；以后不会再提示。

完整说明与支持入口见 [Lumen 官网](https://ihopefulchina.github.io/Lumen/) 和 [GitHub Issues](https://github.com/ihopefulChina/Lumen/issues)。
