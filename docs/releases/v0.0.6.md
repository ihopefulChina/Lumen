## Lumen 0.0.6

这一版补上访达工作流里最重要的安全感：重命名或移动之后，可以立即反悔。

### 安全撤销

- 对象重命名、文件夹重命名和同一 Bucket 内移动完成后，顶部提示会显示「撤销」。
- 也可以从「编辑」菜单撤销，或直接按 `⌘Z`。
- 文件夹撤销会恢复完整目录结构，以及随路径移动的侧边栏收藏。
- 撤销前会检查原位置；如果其他客户端已经创建同名对象，Lumen 会停止并保留撤销机会，不会覆盖远端内容。
- 失败的撤销可以重试，只有云端逆操作完整成功后才会清除记录。

### 明确的边界

- 0.0.6 保留当前会话内最近一次可撤销操作，不提供多级历史或重做。
- 复制、上传、新建文件夹和删除不会显示成可撤销；删除仍会在执行前确认。
- 撤销只在原账号和原 Bucket 中可用，切换回来后可继续操作。

### 仍然熟悉的 Mac 操作

- Return 原地重命名，Esc 取消编辑，双击或 `⌘↓` 打开，空格快速查看。
- 文本编辑中的 `⌘Z` 仍优先撤销输入内容，不会误触发云端移动。
- 普通状态提示保持短暂，带撤销动作的提示会停留更久，两个按钮拥有独立点击区域。

系统要求：Apple Silicon，macOS 15 或更高版本。安装包和软件内更新使用 Sparkle Ed25519 签名验证。

> 已安装 0.0.4 或 0.0.5 的用户可以在「Lumen → 检查更新…」中直接安装 0.0.6，安装完成后软件会自动重新打开。0.0.3 及更早版本需要手动安装当前版本。
