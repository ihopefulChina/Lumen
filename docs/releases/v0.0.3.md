## Lumen 0.0.3

这一版集中修复浏览、传输和本地文件工作流，让主要交互更接近 macOS 访达，并重新整理了产品文档与应用图标。

### 改进

- 网格单击会立即高亮，双击文件夹会先选择再打开。
- 支持 `⌘` / `⇧` 多选、空白处取消、方向键移动、Return、空格和 Delete。
- 列表使用原生 macOS 表格选择；状态栏和检查器能正确汇总多选项目。
- 失败的上传和下载可以按原对象路径重试。
- 账号、设置、公开权限警告和更新提示更清晰。
- README 改为产品优先的 Mac 软件介绍，下载、使用、安全与限制信息更容易找到。
- 使用新的冷蓝文件夹托盘图标；图标主体沿用旧版的光学尺寸，不会在 Dock 或安装包里显得偏大。

### 修复

- 防止切换账号、Bucket 或文件夹后，较慢的旧请求覆盖当前内容。
- 下载和重命名不再静默覆盖同名项目，并阻止本地路径穿越与符号链接逃逸。
- 修复分片失败清理、取消任务资源释放、临时文件清理和冷启动文件接收。
- 修复特殊字符对象路径、签名链接、自定义 Endpoint 和不完整分页处理。
- 更新器只接受本仓库对应版本的精确 DMG 文件。

系统要求：Apple Silicon，macOS 15 或更高版本。
