# Lumen 1.0.3

这是一次以数据安全、完整文件浏览和 macOS 操作为重点的修复版本。

## 修复

- OSS 浏览器默认展示所有对象类型，并恢复窗口底部的 Bucket 与完整对象路径。
- 账号表单恢复 `⌘C`、`⌘V`、`⌘X`、`⌘A` 等原生文本编辑快捷键；STS Token 改为安全输入。
- 修复同 Bucket 复制/移动忽略冲突策略的问题；“询问”现在会真正等待用户选择。
- 覆盖已有对象只在目标 Bucket 已开启版本控制、并能取得精确 `versionId` 时执行；提交前创建私有安全备份。批量操作中途失败时只回滚本次响应返回的精确版本，结果无法确认时保留当前目标和备份供人工核对，不再覆盖并发写入。跨 Bucket 中转完整保留 HTTP 元数据、存储类型、加密设置、ACL 与标签。
- 上传任务固定使用发起时的账号和 Bucket，避免快速切换工作区后传错位置。
- 修复续传下载的 ETag/Content-Range 校验、源文件变化、CRC64、排队任务暂停、传输限速和 Retry-After 处理。
- 修复钥匙串与传输日志错误被静默忽略的问题；恢复或保存失败会明确提示。
- 修复自定义/path-style Endpoint 的公开链接与签名链接路径。

## RAM 权限变更

- 安全复制、移动、覆盖与删除会查询 Bucket 版本控制状态；自定义 RAM 策略需允许 `oss:GetBucketVersioning`，查询失败时操作会安全取消。
- GUI 的替换上传、覆盖复制和对象元数据修改要求目标 Bucket 已开启版本控制；未开启时请使用跳过或“保留两者”。
- 自动移动只在来源和目标 Bucket 都已开启版本控制、且 OSS 返回可精确验证与回滚的 `versionId` 时执行；未开启、已暂停或状态未知时请改用复制并手动核对来源。
- 为完整保留对象权限，并在版本控制 Bucket 中按精确版本复制或回滚，需要按场景允许 `oss:GetObjectAcl`、`oss:GetObjectVersion` 与 `oss:DeleteObjectVersion`。
- 复制对象标签需要 `oss:GetObjectTagging` 与 `oss:PutObjectTagging`；SSE-KMS 对象还需要目标密钥对应的 KMS 解密与数据密钥权限。

## lumen-mcp 1.0.2

- 上传默认拒绝覆盖，只有明确传入 `overwrite=true` 才替换远端对象。
- `list_objects` 支持 `continuation_token`，可完整翻页。
- 本地上传和下载限制在允许目录内，并阻止符号链接逃逸。
- 修复 HTTP 自定义 Endpoint、重定向签名头、跨卷下载提交、Content-Type 换行注入、安装 dry-run 与退出码。
- 新增完整 Swift 6 测试与 npm 打包校验。
- 默认安全上传新增 Bucket 版本控制预检，需要 `oss:GetBucketVersioning`；权限缺失或版本状态不安全时 fail-closed。

## 系统要求

- macOS 15 或更高版本
- Apple Silicon Mac
