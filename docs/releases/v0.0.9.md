# Lumen 0.0.9

这一版补齐了一套更完整的 Finder 工作流：从整个 Bucket 找到对象，可靠地传输和整理，再在需要时恢复历史内容。

## 查找

- 搜索可在「当前文件夹」与「当前 Bucket」之间切换。
- Bucket 搜索支持类型、大小和修改时间筛选，显示分页扫描进度，也可以随时停止。
- 侧边栏新增最近修改、大文件、已删除对象和失败传输。

## 传输

- 新增独立传输中心，可暂停、继续、重试、调整队列顺序，并显示速度和剩余时间。
- multipart 上传与 Range 下载会保存检查点；暂停或重新打开 Lumen 后可继续。
- 新增上传/下载独立并发数、方向限速、默认下载位置、冲突策略和完成通知。
- 同名项目可选择询问、替换、跳过或按访达方式保留两者。

## 恢复

- 对象菜单新增版本历史，可将历史版本恢复为新的当前版本。
- 「已删除」位置可以恢复精确的 delete marker。
- 新增对象属性编辑，可修改 Web 属性、用户元数据和最多十个 OSS 标签。

## 整理

- OSS 文件或文件夹可以直接拖到访达；多选会保留在「Lumen 下载」目录中。
- 复制后切换 Bucket 再粘贴，可安全地跨 Bucket 复制或移动。
- 同账号同地域使用云端复制；跨地域或跨账号会在确认后经由这台 Mac 中转。
- 跨 Bucket 移动只在全部复制成功后删除来源。

## Mac 体验

- 支持原生窗口标签页，`Command–N` 新建窗口，`Option–Command–L` 打开传输中心。
- 更新了帮助、README、官网与完全虚拟的产品截图。

## 系统要求

- macOS 15 或更高版本
- Apple Silicon Mac

完整说明与支持入口见 [Lumen 官网](https://ihopefulchina.github.io/Lumen/) 和 [GitHub Issues](https://github.com/ihopefulChina/Lumen/issues)。
