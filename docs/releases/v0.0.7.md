# Lumen 0.0.7

这次更新把重点放在可靠性、安全边界和日常使用的连贯性上。

## 新变化

- 新建连接默认保持私有；切换为公共读写前会明确确认风险。
- 账户配置采用原子写入并保留可恢复备份，损坏的数据会隔离保存，不再静默覆盖。
- OSS 临时网络错误会自动进行有限次数重试，每次请求都会重新签名。
- 传输队列会保存可恢复的历史；应用意外退出后，可重新选择本地文件并重试中断任务。
- 开启版本控制的 Bucket 删除对象后，可通过精确移除本次 Delete Marker 撤销删除。
- 新增原生帮助窗口和隐私安全的诊断报告，诊断内容不会包含密钥、本地路径或对象地址。
- 完善无障碍标签、失败原因提示、隐私说明、支持页面与安全问题反馈流程。
- 自动更新继续由 Sparkle 提供，检查到新版本后可在应用内安装并重新启动。

## 系统要求

- macOS 15 或更高版本
- Apple 芯片 Mac

完整使用说明与问题反馈入口见 [Lumen 官网](https://ihopefulchina.github.io/Lumen/) 和 [GitHub Issues](https://github.com/ihopefulChina/Lumen/issues)。
