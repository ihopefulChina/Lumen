# Lumen 1.0.0

这是第一个正式版本。相比 0.0.9，这一版把浏览和整理的手感打磨了一遍，也修掉了一批会影响日常使用的稳定问题。

## 浏览和选择

- 网格和列表共用同一套点击逻辑：按下即选中，支持 Command 多选、Shift 连选，双击打开文件夹或快速查看文件，点空白处取消选择。
- 列表模式下点名称列终于能选中了；双击任意一列都可以打开项目。
- 修掉了列表模式里连续进入几层文件夹、再点后退时卡住或崩溃的问题（表格行更新时环境丢失导致的崩溃）。
- 编辑文本时按 Command–V 现在会正常粘贴文本，不会误触发云端粘贴；对话框打开时也不再抢 Esc、回车、空格和方向键。

## 传输

- 失败的上传会中止未完成的 multipart 上传，失败的下载会清理临时文件，不再在 OSS 和本地留下残留。
- 暂停最后一个任务不再误报「全部完成」；取消排在队列里的任务也会正确结束。
- 分片检查点改为按节拍写入，大文件传输时不再频繁整本重写日志。
- 传输记录损坏或重复时也能正常恢复，不会崩溃。
- 一批文件里有重名时，「覆盖」策略会改名而不是互相覆盖。
- 拖到访达的导出遵守下载限速；清理旧导出缓存时单个损坏目录不会阻断新导出。
- 下载到外置磁盘不再因为跨卷移动失败；已经下载完但没来得及清检查点的任务，续传时直接视为完成。
- multipart 续传在服务端 uploadId 过期时会自动重新开始，而不是报错。

## 整理和删除

- 重命名或移动在「复制成功、删源失败」时，会刷新列表并明确提示，不再假装操作完全失败。
- 拖拽移动时，已经在目标位置的项目会被跳过，不再拖累整批操作。
- 删除确认框里的数量与实际删除范围一致。
- 跨账号整理时，源 Bucket 从来源账号解析，不会再误用目标账号的同名 Bucket。
- 剪贴板里只有图片时也可以「粘贴上传」；临时文件写失败不再留下悬空文件。

## 其它

- 首次传输后系统一直无法快速退出的问题（sudden termination 引用计数泄漏）。
- 对象属性保存一半失败时，界面会如实反映已经写进去的部分。
- Bucket 搜索的「停止」会真正取消请求；「最近 N 天」筛选不再命中过期缓存。
- 重命名文件夹 `a` 不再误改 `ab/` 下的常用位置；只选中一个文件夹时按空格等于双击打开。
- 小于 1 KB 的文件不再显示成「0 KB」；补全 heics、dib、cur、j2k 等内容类型。
- 上传路径模板的 `{name}` / `{ext}` 按文件名计算，文件夹上传时不再把子路径拼进模板。
- 自定义 Endpoint（路径式）会把 Bucket 放进 URL 路径；处理后的图片下载不再误报 CRC 校验失败。
- 响应头大小写冲突、重复键等边界情况不再导致崩溃。
- 设置里的并发数、外观等修复：Release 构建不再要求开发者团队（默认 ad-hoc 签名，发版流程使用自己的签名覆盖）。

## 系统要求

- macOS 15 或更高版本
- Apple Silicon Mac

> 目前安装包使用 ad-hoc 签名（暂未配置开发者证书）。首次打开如果被 macOS 拦下，在访达中右键 Lumen 选择「打开」即可；以后不会再提示。

完整说明与支持入口见 [Lumen 官网](https://ihopefulchina.github.io/Lumen/) 和 [GitHub Issues](https://github.com/ihopefulChina/Lumen/issues)。
