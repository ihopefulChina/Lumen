# Lumen 0.0.8

这一版继续收紧 Lumen 的 macOS 交互：浏览窗口把空间还给内容，账号与设置也改成更接近系统应用的表达。

## 新变化

- 移除常驻右侧信息栏。工具栏的信息按钮或 `⌘I` 会按需打开当前文件夹、所选对象或多选项目的信息窗口。
- 信息窗口仍可快速查看、下载、复制链接和删除；关闭后不会挤压浏览区域。
- 添加与编辑账号改用原生 macOS 分组 Sheet，操作按钮、连接状态和钥匙串说明更清楚。
- 新账号的对象权限默认改为「继承存储空间」，上传时沿用目标 Bucket 的 ACL；已有账号的设置不会被自动改写。
- 修复「继承存储空间」被错误显示为公开权限警告的问题。只有明确选择公共读或公共读写时才会提示风险。
- 设置扩展为「通用 / 传输 / 账号」三页，可选择默认网格或列表视图、清除已结束的传输记录，并验证账号连接。
- 设置中的添加、编辑和删除账号入口现在会在当前设置窗口中正确显示和完成。
- 自动更新继续支持在应用内安装；完成后 Lumen 会自动重新打开。

## 系统要求

- macOS 15 或更高版本
- Apple 芯片 Mac

完整使用说明与问题反馈入口见 [Lumen 官网](https://ihopefulchina.github.io/Lumen/) 和 [GitHub Issues](https://github.com/ihopefulChina/Lumen/issues)。
