# Lumen 1.0.1

这是一个修复版本。1.0.0 的软件更新源配置有误，导致「检查更新」始终失败。这一版把更新源迁移到 GitHub Pages，并同步了发版流程。

## 修复

- 软件更新源从 GitHub Release 资产切换到 GitHub Pages（`https://ihopefulchina.github.io/Lumen/appcast.xml`），解决更新检查 404 的问题。
- 发版脚本 `package-dmg.sh` 现在会自动把生成的 `appcast.xml` 同步到 `website/` 目录，确保 GitHub Pages 上的更新源始终最新。
- GitHub Pages 部署工作流在 `appcast.xml` 变更时自动重新部署。
- 网站验证脚本增加了对 `website/appcast.xml` 的存在性检查。

## 系统要求

- macOS 15 或更高版本
- Apple Silicon Mac

> 目前安装包使用 ad-hoc 签名（暂未配置开发者证书）。首次打开如果被 macOS 拦下，在访达中右键 Lumen 选择「打开」即可；以后不会再提示。

完整说明与支持入口见 [Lumen 官网](https://ihopefulchina.github.io/Lumen/) 和 [GitHub Issues](https://github.com/ihopefulChina/Lumen/issues)。
