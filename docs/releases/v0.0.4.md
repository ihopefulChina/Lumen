## Lumen 0.0.4

这一版让 Lumen 从“能用的 OSS 浏览器”更进一步，成为更像访达、更适合长期使用的 Mac 工具。

### 新功能

- 按名称、修改日期、大小或类型排序，文件夹始终排在文件前。
- 把常用 OSS 路径加入侧边栏收藏，一次点击直接返回。
- 在同一个 Bucket 内复制、移动、拖放和重命名文件夹；目录结构会完整保留。
- 使用 Sparkle 检查、下载并安装更新，完成后自动重新启动 Lumen。

### 安全与可靠性

- AccessKey Secret 与 STS Token 改存 macOS 钥匙串；旧版本的本地凭证会在启动时安全迁移。
- 上传和下载会核对阿里云 OSS 返回的 CRC64；下载通过校验后才移动到最终位置。
- 云端移动先检查全部目标并完成复制，随后才删除源对象；遇到冲突或失败不会静默覆盖。
- 更新包使用 Ed25519 签名验证，并在解压前完成校验。

### 交互改进

- 网格与列表的选择、高亮、双击打开、拖放和快捷菜单更接近 macOS 访达。
- 完整性校验成功的传输会显示“已校验”，失败信息更明确。
- 排序方式、收藏夹和自动检查更新偏好会保留到下次启动。

系统要求：Apple Silicon，macOS 15 或更高版本。公开 DMG 使用 ad-hoc 签名，尚未经过 Apple 公证。

> 已安装 0.0.3 或更早版本的用户需要手动安装 0.0.4 一次；从 0.0.4 开始即可在软件内完成后续更新。
