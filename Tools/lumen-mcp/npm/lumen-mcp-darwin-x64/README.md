# lumen-mcp-darwin-x64

`lumen-mcp` 的 macOS Intel（x86_64）预编译二进制包，由主包的 `optionalDependencies` 按 CPU 架构自动安装，**请勿直接安装**。

如需让 AI 操作你的阿里云 OSS，安装主包：

```bash
npx lumen-mcp install
```

文档与支持客户端见 [lumen-mcp](https://www.npmjs.com/package/lumen-mcp) 与 [Lumen MCP 指南](https://ihopefulchina.github.io/Lumen/mcp.html)。
