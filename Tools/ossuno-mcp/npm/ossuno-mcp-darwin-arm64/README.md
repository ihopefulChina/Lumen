# ossuno-mcp-darwin-arm64

`ossuno-mcp` 的 macOS Apple Silicon（arm64）预编译二进制包，由主包的 `optionalDependencies` 按 CPU 架构自动安装，**请勿直接安装**。

如需让 AI 操作你的阿里云 OSS，安装主包：

```bash
npx ossuno-mcp install
```

文档与支持客户端见 [ossuno-mcp](https://www.npmjs.com/package/ossuno-mcp) 与 [Ossuno MCP 指南](https://ihopefulchina.github.io/Ossuno/mcp.html)。
